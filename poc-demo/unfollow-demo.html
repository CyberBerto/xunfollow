🐦 X Unfollow - Proof of Concept

See how browser-based automation works (no Tauri needed!)

💡 How It Works

  • Extension runs directly on x.com in your browser
  • Finds "Following" buttons using DOM selectors
  • Clicks them to unfollow with rate limiting
  • No external app, no Rust, no complicated setup!

🔍 Core Logic Demo

This is the actual code that would run on X.com:

// Find all "Following" buttons on the page function findFollowingButtons() { const selectors = [ 'button[data-testid$="-unfollow"]', 'button:has(span:text("Following"))', 'div[role="button"]:has(span:text("Following"))' ]; return document.querySelectorAll(selectors.join(',')); } // Unfollow one user with delay async function unfollowOne(button) { button.click(); // Click "Following" await delay(500); // Wait for modal // Click confirm button const confirmBtn = document.querySelector( 'button[data-testid="confirmationSheetConfirm"]' ); if (confirmBtn) confirmBtn.click(); // Random delay between unfollows (30-60s) await delay(30000 + Math.random() * 30000); }
